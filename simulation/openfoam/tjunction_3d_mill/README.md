# tjunction_3d_mill — 3D fidelity twin of the millable chip

The `tjunction_2d_mill` junction geometry in full 3D (half-depth domain,
symmetry plane at mid-depth), velocity-driven at the verified 2D reference
point. Exists to measure the cost of the 2D shortcut — square channels
have corner gutters that 2D cannot represent. `system/blockMeshDict` is
generated by `gen_blockmesh.py` (84k cells at `--dx 20`).

**Result** (see [`../results/mill3d_2026-07/`](../results/mill3d_2026-07/)):
slug length transfers from 2D within +3%; droplet speed is ×1.43 and
frequency ×2.4 versus 2D. Hardware first-light expectations: ~620 µm slugs
at ~27 Hz, ~40 mm/s — film at ≥120 fps.

Run cost: 8.25 h on an M4 mini (6-way MPI in Docker, 2.4× parallel
speedup, smoke-gate scripts in the repo history). Extraction: use
`scripts/extract_mature_droplets.py --w-main-um 400 --x-junction-um 2400
--max-advance-um 250 --growth-threshold-um 40` (the advance cap must suit
this case's 5 ms write interval — droplets move ~200 µm/frame).
